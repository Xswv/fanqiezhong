# 番茄钟计时器 🍅

一个简洁现代的桌面番茄时钟软件，使用 Python + Tkinter 构建。

## 功能特点

- ⏱️ **番茄钟计时** - 工作时间 + 短休息 + 长休息
- 🎨 **简洁现代界面** - 深色主题，圆形进度条
- ⚙️ **自定义时长** - 可调整工作和休息时间
- 🔔 **系统通知** - 计时结束时提醒
- 🍅 **番茄计数** - 记录每日完成的番茄数
- ⌨️ **快捷键支持** - 空格、R、Esc 快速操作

## 安装和运行

### 方式一：直接运行

```bash
python pomodoro.py
```

### 方式二：双击运行

双击 `run.bat` 文件即可启动。

### 方式三：安装依赖后运行（可选，用于系统通知）

```bash
pip install plyer
python pomodoro.py
```

## 使用说明

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `空格` | 开始/暂停计时 |
| `R` | 重置计时器 |
| `Esc` | 打开设置 |

### 界面说明

- **红色** - 工作时间（默认25分钟）
- **绿色** - 短休息（默认5分钟）
- **蓝色** - 长休息（默认15分钟，每4个番茄后）

### 设置

点击设置按钮或按 `Esc` 键可以：
- 自定义工作时间
- 自定义短休息时间
- 自定义长休息时间

## 系统要求

- Python 3.6+
- Windows / macOS / Linux

## 自定义开发

如需修改界面颜色，编辑 `pomodoro.py` 中的 `COLORS` 字典：

```python
COLORS = {
    'work': '#E74C3C',      # 工作时间颜色
    'short_break': '#27AE60',  # 短休息颜色
    'long_break': '#3498DB',   # 长休息颜色
    'bg': '#1E1E2E',        # 背景色
    # ... 其他颜色
}
```
